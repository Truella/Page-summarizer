Summary

  • Chrome extensions use Manifest V3, which replaces background pages with service workers for better performance and security.
  • The popup, content script, and service worker are three isolated environments that communicate via message passing.
  • Permissions must be declared upfront in manifest.json — only request what your extension actually needs.
  • Content scripts run inside the webpage context and can read the DOM, but cannot access extension APIs directly.
  • Storage via chrome.storage.local persists across popup closes and service worker sleep cycles.

Key Insights

Service workers are ephemeral — never store state in global variables, use chrome.storage instead.

The security boundary between worlds prevents one compromised script from affecting the entire extension.
